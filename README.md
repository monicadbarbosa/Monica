# Portfólio Mónica — versão fiel à referência

Esta versão foi refeita para seguir a composição da imagem enviada: riscas rosa, barra superior arredondada, hero orgânico, faixa tipográfica, grelha de trabalhos, secção multimédia com moldura de telemóvel, apresentação e rodapé.

### Publicar no GitHub Pages
1. Cria um repositório no GitHub.
2. Envia todos os ficheiros e a pasta `assets`.
3. `Settings` → `Pages` → `Deploy from a branch`.
4. Escolhe `main` e `/ (root)`.

### Nota
As imagens da pasta `assets` são recortes da referência fornecida, usados para reproduzir a composição enquanto não temos os ficheiros originais dos projetos. Quando tiveres as imagens originais, basta substituí-las mantendo os mesmos nomes.
